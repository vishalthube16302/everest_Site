# Everest V2 documents

Read `STATUS.md` first. Then open only what the task needs.

| If the task is about | Open |
|---|---|
| Where the project stands | `STATUS.md` |
| Why something was decided | `DECISIONS.md` |
| What to do in a phase | `phases/phase-N.md` |
| Tools and hosting | `architecture/stack.md` |
| Tables and security | `architecture/data-model.md` |
| Pages and URLs | `architecture/routes.md` |
| Colours, type, layout | `design/tokens.md` |
| Page sections and components | `design/components.md` |
| What the site may claim | `content/verified-facts.md` |
| Products to add or fix | `content/catalogue.md` |
| Reviews we may quote | `content/reviews.md` |
| Waiting on the owner | `content/open-questions.md` |
| Photos | `media/image-pipeline.md` |
| Films | `media/video-pipeline.md`, `media/video-status.md` |
| Projects and hosting names | `ops/environments.md` |

| Admin panel, logins, publishing | `ops/admin-panel.md` |
| Going live | `ops/launch-checklist.md` |
| Going back | `ops/rollback.md` |
| New site code | `../web/` |
